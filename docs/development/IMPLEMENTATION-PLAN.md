# 开发顺序、验证与交付门槛

状态：排期与验收依据。**平台数据库方向已确认改为 MySQL 8.4 LTS / InnoDB；以下业务工程、数据库测试和真实试验仍未开始。** 本次仅更新既有设计分支，不将换库授权扩展成业务实施或部署授权。

## 按一条纵向链路交付

| 阶段 | 应交付什么 | 退出条件 | 尚不能宣称什么 |
| --- | --- | --- | --- |
| D0 合同与依赖验证 | 版本清单；Java/TS 可复算合同样例；目标 Provider 差距清单；MySQL 类型/锁/约束最小验证 | JDK/Boot/Connector-J/Flyway/SDK 兼容；实际 MySQL 8.4 补丁/镜像冻结；12 方法与错误/状态映射可审核；身份与部署策略明确 | SDK 和数据库语法可用不等于业务链路通过 |
| D1 最小服务骨架 | Maven/React 工程、MySQL 迁移、合成测试身份、授权门禁、日志、持久化 Provider 替身 | 空库启动/升级/重启；跨用户拒绝；消息与命令幂等；真实 MySQL 并发预占、唯一约束及崩溃恢复 | 测试身份不等于真实登录，替身不等于 ACP/总控 |
| D2 完整服务闭环 | 固定流程；系统内环境/绑定；对话、审批、任务、结果、文件和管理记录 | 页面创建配置和成员后完成同一服务链路；真实上传解析与确定性计算；正文/下载逐项授权 | 用合成数据跑服务不是接入业务资源 |
| D3 两条受控后端 | 总控适配与 ACP Runner、代码和 MCP 网关、真实模型观察 | 逐项共同契约；总控路径先过，再关闭总控验证直连；预算/权限/隔离留真实证据 | 一路通过不能宣称两路均支持 |
| D4 获权测试环境试点 | 指定系统、数据集和资源范围；身份源；责任人；备份与运维手册 | 用户复算证据与文件并确认；故障演练不重复执行；平台库和 Runner 日志恢复、接管经负责人验收 | 不自动推广至生产、写入或多 Agent 调度 |

D1/D2 优先可运行纵向闭环。配置先支持必要字段，管理仍用列表/表单；自由流程画布、全面知识库、任意 Skill 脚本、复杂多节点和受控写入延后。扩展沿现有接口增加配置与适配测试，不在 Controller 加型号判断。

## 开发任务拆分

1. **合同与结构**：三个 Maven 模块和前端工程；依赖锁定、MySQL/Flyway 迁移验证、OpenAPI/Schema/DTO 生成检查、模块依赖测试。实现不可变引用、错误与时钟/ID 端口；统一 UUID/UTC/Decimal/JSON 映射。
2. **身份与配置**：成员角色、系统下环境、对象草稿/显式发布、Agent/模型/资源绑定、有效能力预览。预览与发布同规则；模拟发现只能在测试配置启用。
3. **对话与材料**：持久消息、标题独立 CAS、上传隔离解析、上下文清单、无工具理解用途、SSE 恢复。记录采用输入修订，迟到回调不得覆盖新计划。
4. **执行与审批**：固定流程、唯一 Binding、排队准入、额度总分账、outbox/inbox、权限桥、停止和核查；MySQL 并发与失联测试先于真实 Provider。
5. **结果与管理**：确定性计算、证据等级、产物导入、待验证/解决、接管包、任务/审批列表、正文租约和审计。
6. **适配与试点**：经授权取得实际版本与资源，按 D3/D4 验收；真实能力不足反馈设计，不临时绕过门禁。

每项合并条件包含功能、失败路径、权限与迁移；不能先交付可见按钮，再把服务端守卫留待补做。

## 测试重点

| 层次 | 必测场景 | 证据归属 |
| --- | --- | --- |
| 领域单元 | 输入修订、计划依赖、标题手动优先、权限交集、额度继承、非法状态边 | Java 规则测试，不依赖真实网络 |
| MySQL 8.4 集成 | 同键竞争、生成列唯一 Binding、审批 CAS、总分账原子预占、事件重复/乱序、UTC 跨日、发布/撤权与准入竞争 | 固定 MySQL 8.4 的 Testcontainers 或等价隔离实例；H2、SQLite、MariaDB 或旧版本不能替代锁/约束证据 |
| 故障注入 | outbox 前后/发送后崩溃、接纳回执丢失、租约过期、停止与完成交错、COMMIT 断连、备份恢复 | 原执行 ID/命令键、数据库前后状态和外部夹具事实 |
| 服务授权 | 未开通零权限、跨用户/租户、流/历史/附件/下载独立授权、撤权与正文租约到期 | HTTP 集成测试；隐藏按钮不算权限验收 |
| UI 端到端 | 登录→选择→上传→追问→审批→执行→交付→验证；后台定位同一问题；刷新/切页/多标签不重复启动 | 正式前端连接本地服务；历史 195 项原型检查只作体验参考 |
| Provider 共同契约 | CP01–CP22；用途、排队过期、跨连接额度、已知/未知用量组合 | 两后端各自实际版本、制品与资源身份；not_run 不改成 pass |
| 资源隔离 | Agent 不申请权限仍不能越权；目录链接逃逸；Git 凭据泄漏；MCP schema 漂移/恶意链接；附件解压及输出超限 | OS/网络/工具拒绝回执，模型自述不算 |
| 证据交付 | 区间/时区/币种/单位不一致，代码版本不符，延迟/截断，哈希错，CSV 公式注入，用户未解决 | 输入和计算可复算；不以语言流畅度判断正确 |

排队未开始因批准过期、相关依赖变化或额度归零而阻断；已合法开始的执行不因普通展示/背景编辑被重写。撤权立即阻断未来动作，不享受旧快照豁免。出队、发送和首次接纳之间的延迟/过期竞争也必须覆盖。

## MySQL 专项退出条件（全部待实现验收）

每项保存精确 Server / Connector-J / Flyway 版本、镜像摘要、DDL 和 SQL、隔离级别、连接参数、并发时序、前后数据及预期结果。不得只记录“连接成功”。

| 编号 | 场景 | 必须证明 |
| --- | --- | --- |
| MY01 | 空库迁移、升级、重启、迁移中断 | 平台与 Runner 独立历史/账号；实际结构与历史一致；中断不误报就绪；不是靠多 DDL 回滚或盲目 repair |
| MY02 | 同 NodeRun 并发插入未关闭 Binding、关闭后留历史 | 生成列唯一索引阻止第二条未关闭记录；多条已关闭历史合法；关闭须有证明 |
| MY03 | 命令、事件、一次消费同键竞争 | 相同内容复用原回执，不重复扣费；同键不同内容冲突；大小写及尾随字节不被默认 collation 合并 |
| MY04 | 两任务抢最后一个并发槽/最后一份预算 | 总账、分项、预占、节点、审计、outbox 一起提交或回滚；不同连接不绕过用户总额 |
| MY05 | 首个周期账户不存在时并发创建 | 稳定父/守卫锁与唯一键收敛；不能把空 SELECT 结果当范围锁；跨日旧未知预占不丢 |
| MY06 | 出队与审批过期、额度下降、配置发布、撤权竞争 | 锁后按当前版本与时间准入，失效不发送；降限不抹消已有事实；发送/接纳间过期另有合同证据 |
| MY07 | 多消费者领取、锁住队列项、锁住额度行 | SKIP LOCKED 只跳过队列项，额度/权限锁不能被跳过；检查索引、锁范围和最老待办等待 |
| MY08 | 死锁、锁等待超时、COMMIT 时断连 | 本地用例完整回滚或按原命令查回执；有界重试不重复外部动作，不在部分事务上继续 |
| MY09 | UTC/微秒、非 UTC JVM、跨时区/夏令时、Decimal 上界 | 时间往返和期限一致；精度与舍入明确；不隐式截断/溢出；业务时区周期独立 |
| MY10 | JSON 往返、重复键、跨 Java/TS 哈希、UUID 字节映射 | 合同规范化决定哈希，不依赖数据库 JSON 输出；唯一标识和字节顺序保持一致 |
| MY11 | 事件序号竞争、回滚后重试、SSE 断线 | 会话计数行与事件同事务，不由 AUTO_INCREMENT 大小推定提交顺序；不丢迟到提交 |
| MY12 | 接纳日志持久化、进程启动间崩溃、start 与 closeSubmission 竞争 | 唯一接纳与启动拥有者，旧租约 fencing；未知先核查；数据库回执不虚构外部未执行 |
| MY13 | 运行账号尝试 DDL、跨库读写，Agent 尝试连接数据库 | 真实权限拒绝；运行/迁移/外部业务数据源账号独立，不能只靠应用约定 |
| MY14 | 平台/Runner 两库、文件和密钥引用恢复 | 恢复后先冻结分派、核查所有未决执行；不以旧备份重放原任务，记录所用恢复点 |

MY01–MY03、MY09–MY10 的最小数据库语义实验可在 D0 完成，其余随 D1/D2 和 Runner 实现验证；真实 Agent/外部总控的结论仍必须等 D3，夹具不能替代。

## 运行和运维初值（建议，非已测指标）

首批按单台主机、一个平台实例、一个 Runner 和有界并发设计。消息保存不等待模型；SSE 用心跳和有界缓冲，慢订阅者重取快照。连接池、工作线程、Agent 并发分别限流，不随虚拟线程数量放大。

拟定起始值：分页 50/最大 100；上传单文件 20 MiB；解析 60 秒；单次发现 30 秒；SSE 心跳 15 秒。批准期限、任务时限、日志/文件保留期和资源调用上限按环境策略设置。这些只是压测输入，不是已测能力；超时不意味着外部已停止。

MySQL 数据库连接必须验证实际 database、InnoDB、严格 SQL mode、UTC 会话、READ COMMITTED；使用 binlog 时核验 ROW 和落盘策略。TLS、凭据与受控网络按部署环境配置，不为连通而默认关闭证书校验或使用 root。池中时区/隔离级别不得因一次特殊查询遗留到其他事务。

监控至少覆盖：最老 outbox 年龄、接纳未知数/持续时间、审批到期未分派、活跃槽、未上报用量、产物导入失败、正文拒绝、撤权传播，以及连接池等待、死锁和锁超时。区分服务存活、数据库就绪与环境可执行；连接故障不把已接纳任务改为失败。

部署前验证 TLS/同源 Cookie/CSRF、会话撤销、秘密轮换、隔离模板、数据保留和恢复。邀请制本地账号需密码哈希、登录限流、恢复与会话失效；企业 OIDC 明确 issuer/subject、成员开通和登出失效，不直接信任邮箱域名。

先做单实例备份恢复，不为首批增加 Kubernetes、消息中间件或高可用承诺。MySQL 迁移采用向前兼容和可回退应用版本，破坏性变更另审；原子 DDL 不代表整批迁移可回滚。恢复后暂停分派，核查未决外部执行再开放，不盲目清空队列。
