# ADR-001 当前状态：独立平台与可插拔执行后端

**状态：架构方向已由用户认可；具体实现细节仍需设计评审。**

日期：2026-10-25。用户指示：“合理 那你单独在我的github上开一个新的项目来做，将你的设计文档都先传上去”。

## 采纳的方向

独立建设业务平台，通过执行后端契约接入现有总控，同时保留受控 ACP 直连路线。总控不是平台唯一、不可替换的运行依赖；不 fork 或复制整套总控。

业务平台拥有业务数据、身份、权限、流程、审批责任、预算与验收；总控拥有其被委派执行的任务树与执行尝试；直连宿主负责最小单 Agent 进程/会话。两条路径均通过一致的资源治理。

## 当前解释优先级

本状态记录与决策记录优先于历史 v0.2 的“节点直接映射总控任务”和“总控执行内核必选”。原稿不改动；当前[初始设计](../design/README.md)与[离线原型](../prototype/index.html)统一采用平台管理、执行连接与唯一 Binding。不再另分产品版本。

## 仍待细化

本轮已形成[执行契约草案](../design/EXECUTION-PROVIDER.md)、[五层转换表](../design/STATE-MACHINES.md)和[审批恢复路径](../design/APPROVAL-RECOVERY.md)。这些是获授权的设计完善，不等于逐项批准或已实现。审批桥接、文件传输、隔离方式、模型账号、技术版本、用量精度及部署仍待技术评审与实机验收。

## 验收方向

总控后端跑通一条受控排查；总控关闭时，ACP 直连也独立跑通至少一条基础排查，并持续执行相同权限、审批与预算约束。当前均未实施或验收。
