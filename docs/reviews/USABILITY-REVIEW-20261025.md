# 日常页面可用性走查

日期：2026-10-25。用户认可列表方向，进一步要求页面实用方便。范围：初始设计与离线原型，不接入真实服务。

## 走查与修补

| 日常动作 | 发现 | 改动 / 验证点 |
| --- | --- | --- |
| 填长配置后应用 | 操作栏容易离开视野，无改动仍可点 | 应用 / 放弃栏保持可见，无改动禁用；确认前仍只改草稿 |
| 修改多页配置后纠错 | 只有一段错误文字，不知道去哪里改 | 按对象与字段提供修正入口；跨页定位、保留其他草稿 |
| 环境增加代码 / 工具 / 方法 | 通用目录链接不带类型，也没有明确返回 | 三类独立入口，返回原环境，整份草稿保持一致 |
| 用键盘调整开关与下拉 | 页面重新绘制容易丢焦点 | 更新后保留当前控件焦点与配置页滚动位置 |
| 找成员或待办 | 只支持 Enter，成员没有搜索 | 提供搜索按钮、空格处理和重置；成员按账号状态筛选 |
| 查看成员现有权限 | 原界面只显示固定三个环境，不便核对完整授权 | 展示所有现有环境，区分可新增范围；仍按原授权边界校验 |
| 改成员后临时关闭 | 编辑内容直接丢失 | 按演示身份保留内存草稿，显示未保存；可明确放弃或确认保存 |
| 审批具体问题 | 主体主要解释策略，缺少本轮条件 | 显示固定问题与本轮补充，审批意见进入该计划历史 |
| 查看自动授权历史 | 旧自动执行容易取到最新准备信息 | 自动执行单独保留当轮准备快照，后续日期与条件不覆盖历史 |
| 看执行状态 | 页签与下拉可能显示不同状态 | 状态选项补全并同步，返回列表保留筛选 |
| 查用户记录 | 搜索与重置不明确 | 显式按钮和返回路径，正文授权继续独立 |

## 验证方法与证据

采用源码核对、项目本地 `file://` 浏览器测试、DOM 行为和截图检查。内置浏览器自动化因 URL 策略无法绑定用户当前本地文件页，本轮未控制该页，也没有将测试环境说成用户当前页面。已有测试使用单独的无头浏览器实例，不改变用户已有演示内容。

新增 13 条日常路径用例，保存在 [usability-checks.cjs](../prototype/tests/usability-checks.cjs)，覆盖完整的纠错与目录往返、确认前后配置区别、成员草稿 / 身份隔离、审批范围与意见、搜索、键盘和窄屏操作；与旧有执行 / 审批 / 资源与状态用例一起回归。最终结果和源码摘要见[检查报告](initial-design-checks/README.md)。

## 保留限制

本轮只证明离线原型能按这些路径操作；没有真实用户访谈或生产可用性验收。没有服务端持久化、网络加载失败、并发冲突处理、真实权限、模型 / ACP / MCP 调用或付费资源。模拟刷新会重置全部内容，草稿保留仅限本页内存，不代表后台保存。

历史 v0.2 和归档保持不变；当前变更尚未提交或推送。

## 历史原型对照与配置链路复查

按用户明确偏好对照历史任务、流程和用户对话：管理端回到熟悉的白卡列表 / 表单；用户端保留直接提问，补业务状态和可按需打开的问题信息。技术演练不再占据主操作。对照截图保存在本轮检查目录，均为无真实执行的原型画面。

同时发现原型只校验环境 / 模型与执行方式，尚未逐项约束流程依赖；本轮加入固定检查模板的发布和依赖解析。环境未开放、角色无权、缺 Skill / 限定 MCP 工具 / 必需代码，均不生成 Binding；同名工具不能跨连接替代。代码实际版本改为未知，不再拿固定 demo 版本当已读取代码。接入和运行诊断控件标明未发布草稿，预算等未完成的硬限制没有伪装为已经生效。

[主线设计](../design/USER-FLOW-AND-CONFIG.md)区分本轮已联动内容与真实模型、工具、资源身份、预算和隔离仍未验证的部分。
