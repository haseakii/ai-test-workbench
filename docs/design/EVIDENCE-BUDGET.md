# 证据一致性与预算边界

状态：初始设计；字段与规则未获真实业务验收。

## 证据字段与结论等级

每份证据记录 evidenceId、bindingId、来源类型及定位、contentHash、collectedAt、system/environment、部署 commit 与代码 commit、业务区间、时区、边界是否包含、数据库 snapshot/asOf、报表生成时间、watermark/延迟、截断/采样及完整性状态。未知用 null/unknown 明示，禁止填默认当前时间或伪造 commit。

| 检查 | 不一致/未知时的处理 |
| --- | --- |
| 部署与代码 | commit 不匹配则不把代码推断标为已证实根因；可保留待验证假设。 |
| 报表与明细区间 | 统一时区、开闭区间、状态、币种和单位；无法统一则停止确定性金额结论。 |
| 数据时点与延迟 | 展示各自 asOf、水位和允许延迟；超出业务容差时重取证或限定结论范围，不静默拼接。 |
| 查询截断/采样 | 差异文件标明覆盖范围，不声称全量核对。 |
| 来源授权或完整性失效 | 禁止下载/继续引用；保留不可访问原因，不伪装空结果。 |

结论等级：confirmed（必要证据一致且可复算）、qualified（有边界的部分结论）、insufficient（不足以下结论）。Agent 自述和模拟演示不能升级等级。确定性计算须记录工具、输入哈希、规则和产物哈希；用户验收独立保存 resultRevision。

## 预算账本

预算预占、实际用量、估算、未上报、结算与释放分开。用量键为 provider + run + meter + sourceId；累计事件按高水位计算增量，不能把父汇总和子任务再相加。修正事件必须关联被修正记录；负数/倒退进入核查，不悄悄退费。币种、计量单位和汇率时间分别记录，不把 Token 当金额。

| 限制 | 可宣称的等级 | 验收证据 |
| --- | --- | --- |
| 并发/新调用数 | 仅经分派入口及所有子任务共享计数实际阻断后为 verified | 超限请求确实未启动 |
| 行数/查询时间/文件大小 | 资源服务或数据库的实际限制 | 超限拒绝/截断回执 |
| 模型金额/Token | 只有实际执行器支持并验证才为硬限制 | 请求及供应商/宿主停止事实 |
| 估算金额/延迟上报 | 软阈值；显示 estimate/unknown | 估算依据、上报延迟与差异 |

无用量上报时默认停止新增计费模型调用；允许不计费的快照、事件、停止、外部结果核查和已有产物导入。确需继续，须有绑定具体运行、额外调用数、金额风险上限及有效期的人工风险决定，并验证执行侧调用计数可强制；不能用一次“继续”放开无限预算。本轮原型仅演示默认阻断。

正在进行的请求可能继续消耗；停止分派不代表费用停止。结果未知保留预占/挂账，安全关闭且计量对账后才能释放可释放部分。完成与用户解决不触发二次计费。
