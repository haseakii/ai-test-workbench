# AI 测试协作平台 · 详细交互原型 v0.2

设计日期：2026-10-25。交付范围：22 个页面 / 视图、24 页设计文档、HTML/CSS/JavaScript 源码和交互检查记录。

## 打开方式

直接用浏览器打开根目录 `index.html`，无需安装依赖或启动服务。使用桌面 Edge / Chrome 查看，先从顶部的“测试工作台 / 总控后台”切换。左侧“原型评审指南”列出了全部页面和演示入口。浏览器允许本地存储时，部分操作状态会保留；“重置演示”恢复初始案例。

这是离线原型。不要输入真实账号密码、密钥、客户资料或数据库凭据。登录字段只做格式演示；身份切换用于评审，不是正式权限系统。任何审批、执行、发布、连接检测、AI 回复都不会调用真实外部服务或消耗模型额度。

## 建议先走三条路径

### 问题排查

打开“当前对话”，观察问题、材料、模型快照和运行状态。点击“推进一步”推进合成事件，再进入“结果与产物”。查看代码 / SQL 证据抽屉，下载合成差异 CSV，选择“确认已解决”或填写原因重新打开问题。也可以从“新建问题”输入目标，进入脚本追问。自由输入不会得到真实 AI 分析，预置报表结果不是自定义问题的实际诊断。

### 审批与执行

切换总控后台 → 审批中心。核对 SQL、目标环境、3 条演示记录、前置版本和验证方法。未勾选确认时无法批准；拒绝或要求调整需要意见。“模拟计划变化”会让旧计划失效。批准后只入队，不直接标记已执行；进入关联任务可手动推进执行、待验证和确认。全过程不会执行 SQL。

### 配置与发布

工作流 → 报表差异核对 → 编辑与试运行。选节点，修改执行器、模型、Skill、MCP、输出变量和限制，保存节点。可以新增、删除、上下排序；校验基本结构，进行结构试运行，再发布本地示例版本。原型不是自由连线画布，也没有真正执行流程节点。

## 页面清单

前台 6 页：发起问题、问题对话、历史问题、结果与验证、知识经验、我的待办。

后台 14 页：总控概览、任务中心、任务详情、审批中心、工作流列表、流程编辑、助手配置、ACP 与模型、Skill 中心、MCP 工具、系统环境、用户权限、额度预算、审计日志。

通用 2 页：登录、原型评审指南。

## 可操作与展示级能力

已实现的本地交互包括：导航、搜索筛选、表单校验、脚本追问、执行状态切换、停止两阶段、失败重试、问题重开、审批状态联动、节点编辑与排序、Skill 草稿校验与发布、模型请求与模拟确认、资源停用、演示身份限制、额度表单、导出与证据抽屉。

展示级内容包括：部分历史问题详情、任务时间线样例、真实连接探测矩阵、日志 / 资源健康、趋势统计、通用配置卡片。部分配置对话框只保存本地草稿，尚不动态重建全部配置关系。审批有效期只展示，没有实际过期调度。

未接入：真实 AI/ACP/MCP、业务代码仓库、数据库读写、服务端身份授权、真实额度账本、病毒扫描、附件解析流水线、对象存储、分布式恢复和实际通知。

## 文件与隐私

选择文件后，PNG/JPG 等图片及 TXT/CSV/LOG 文本片段可以在浏览器内存中预览。PDF/XLSX 只展示元信息，不解析内容。刷新后文件内容不会保留，需重新选择。文件名、输入文本和演示配置可能随本地状态保留；清理浏览器站点存储或重置演示可清除。

内置导出文件仅含 3 行虚构样例，不是用户数据。没有自动上传或外部网络请求。
