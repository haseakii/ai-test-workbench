## 版本与状态

**v0.2 设计与原型：待用户评审。**本轮保留原文件内容，上传原始 ZIP，并将包内 43 个文件逐个展开归档。仅把独立 HTML 按包内名称保存为 index.html；已校验其与此前交付 HTML 的 SHA-256 一致。原型及其状态仍是模拟，不代表后端实现。

**ADR-001 v0.1：待架构审批。**新提案建议独立业务平台，通过适配器接入总控与受控 ACP 直连。它补充并拟修订 v0.2 的执行依赖边界，没有直接修改旧原型、PDF 或 Word。

**本次没有重新运行 v0.2 原型测试。**tests 中报告是原交付包的历史验证记录。本轮检查了 ZIP 完整性、文件清单与独立 HTML 一致性；核查了固定开发提交下的总控入口、外部客户端能力和 ACP 包依赖，并阅读官方协议。

架构核查固定提交：`b9a3af9b7df47b34f8074e3f3bf2cab7668dab80`。这不是用户机器已部署版本的声明；来源和限制见 ADR 第 03 节。

## 建议先批准什么

先确认产品与执行后端的关系、权限与审批归属，以及首版两条链路的验收范围，再安排下一版原型调整和开发。技术方向审批不自动批准真实数据库访问、生产变更或模型账户使用。

归档为复制上传，不移动、不删除其他资料库文件；未更改分享权限。
