# Windows 首装准备版（尚未安装）

推荐主路线是**一份完整便携包＋一个私有本机实例**，不要求普通使用者先配置Java/MySQL/TLS/账号。本目录目前提供依赖检测、只读方案、受限初始化模板和代码准备，**尚未包含或获准下载便携软件，也没有执行初始化的协调器**。此前的已有环境预览包仍保留，不能把它的前置条件说成简单搭建已完成。

## 普通使用者目标

后续软件、机器和初始化范围均获准且实机验收后，目标为3个动作：

1. 解压完整包到本地可写位置。
2. 双击 `Workbench.cmd`。
3. 确认首次创建的私有实例/数据目录和本机端口，等待真正就绪。

目标是无需手工SQL、数据库密码或证书准备；这是待实现/验收的目标，当前不会自动做这些事。默认建议使用当前用户LocalAppData内的专用目录，不会替你选择某台电脑；端口冲突、现有数据或权限不明必须停止，不能静默复用/覆盖。

## 当前可以做什么

`Workbench.cmd requirements` 无需Java即可阅读依赖和未批准状态；不联网、不下载、不初始化。发现 `runtime/java/bin/java.exe` 候选也不会执行，因为Windows版本、官方摘要和使用授权尚未齐备；不会读取手工“批准标志”或把兼容入口成功当成便携首装。

维护者已有可信Java21时可用 `Workbench.cmd setup` 或 `setup --json` 查看只读方案：本机/依赖文件状态、两条路径的成本、两库三分权账号的精确范围、11步初始化动作和模板摘要。返回 `SETUP_PREPARATION_ONLY`、`canInitialize=false`（退出2），不是安装成功。预检不会创建目录、生成凭据、运行候选软件或连接数据库。

`setup/*.template` 默认带拒绝守卫，**不能手工去守卫后运行**；每条SQL语句都被守卫，初始化和正常运行配置分开。未来获准协调器才可绑定范围、模板哈希和具体软件生成私有配置并执行；当前不包含该执行器。

## 剩余依赖与限制

- 便携Java21和MySQL8.4的Windows确切版本、官方包摘要及重分发条件尚未核验。Linux已测的21.0.9+10/8.4.13只是参考，不能据此编造Windows下载文件或SHA。
- MySQL Windows ZIP可能需要MSVC v14/UCRT原生运行库；必须检查所选包和目标机器。app-local部署存在但有许可/维护约束，不能复制System32或自动安装系统运行库。
- 秘密保护代码准备使用Windows当前用户DPAPI与系统自带PowerShell静态调用，不需用户手写脚本；组件/策略不可用就停止，不修改执行策略、提权或回落明文。实际DPAPI、NTFS、共享内存认证、TLS生成和进程能力均待Windows实机验证。

不要求Docker、Node、Maven或Python作为Windows用户运行依赖；维护者构建/校验工具与用户运行前提分开。没有通过安装系统服务、改全局PATH/防火墙/权限或关闭TLS来降复杂度。

## 已有环境只是兼容路径

此前的 `configure/doctor/up/status/stop` 复用已有获准Java/MySQL/TLS/分权账号，向导仍6提示、4必填，且有管理员预先准备工作。保留它用于既有环境，不再为这条路径造另一套自动安装器，也不把管理员步骤隐藏成零成本。程序仍为合成身份/执行器，不能接真实业务数据或冒充生产登录。

## 后续精确确认范围

先完成官方Windows包的版本/摘要/许可核验，再分别审阅：下载/解包这些具体软件但不运行；用户指定的Windows机器与私有路径；仅新私有MySQL实例的系统初始化、两业务库/三分权账号、该实例初始root密码轮换、TLS/DPAPI材料及回环13306/18080端口。任何MSVC安装或app-local文件分发均需单列；旧数据、共享库、系统服务、全局PATH/网络/权限和真实业务资源都不在范围内。

备份需同时保留两库、文件和秘密引用；DPAPI密文不能保证换用户/机器可恢复，恢复方案、备份位置及恢复保护材料需先确认。初始化中断保留原日志/身份/未知结果，不清库、盲repair或重复初始化。详见 `COMPATIBILITY.md` 与 `setup/dependencies.json`。此准备版和Linux离线测试不等于Windows三步首装或项目整体完成。
